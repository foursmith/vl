# 普通快捷键

以下按键按焦点和当前视图生效。启用 Vim 后，文本编辑器的 Normal / Visual 模式使用[Vim 快捷键](VIM.md)，工作区快捷键仍然可用。
`Ctrl+…` 表示同时按下；字母快捷键如 `j`、`s` 使用小写。

## 工作区与标签页

| 按键 | 操作 |
| --- | --- |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | Explorer / Changes / History |
| `Ctrl+P` | 搜索并打开文件 |
| `Ctrl+R` | 打开最近文件夹 |
| `F1` / `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+G` | 跳到指定行或 `行:列`，从 1 开始 |
| `Ctrl+F` / `F3` | 搜索当前内容 / 下一个结果 |
| `F6` | 切换编辑区与侧栏焦点 |
| `Esc` | 普通视图中聚焦侧栏；弹窗中取消；Vim 中返回 Normal |
| `Ctrl+L` | 显示 / 隐藏侧栏 |
| `Ctrl+J` | 显示 / 隐藏输出面板 |
| `Ctrl+D` | 切换统一 / 并排 Diff |
| `F5` | 刷新仓库 |
| `Ctrl+S` | 保存当前文本文件 |
| `Ctrl+W` | 关闭当前标签，未保存时提示 |
| `Alt+Left` / `Alt+Right` | 上一个 / 下一个标签 |
| `Shift+F10` / 鼠标右键 | 打开当前侧栏项或内容的上下文菜单 |
| `Ctrl+Q` | 退出，有未保存修改时提示 |

`Ctrl+C` 在聚焦的文本编辑器或 Diff 中复制选区；在其他普通视图中用于退出。

## 侧栏

| 按键 | 操作 |
| --- | --- |
| `Up` / `Down` 或 `k` / `j` | 上一项 / 下一项，并预览 |
| `Enter` | 打开所选项、切换目录展开状态或执行当前项操作 |
| `Right` | 展开当前项，或打开文件 / Diff |
| `Left` | 折叠当前项，或选择父级 |
| `Delete`（Explorer） | 删除所选文件 / 文件夹，有确认提示 |
| `e`（文件项） | 编辑文件 |
| `Space`（Changes） | 切换所选文件的暂存状态 |
| `s` / `u`（Changes） | 暂存 / 取消暂存所选项 |
| `a`（Changes） | 暂存全部 |
| `c`（Changes） | 提交 |

提交、暂存和编辑是否可用取决于当前条目；只读历史内容保留其操作限制。
终端宽度不足 70 列时，侧栏和内容共用一个区域，通过 `Enter` 和 `Esc/F6` 切换。

## 文本编辑器

本节适用于关闭 Vim 时；Vim Insert 模式也使用普通文本输入和编辑操作。

| 按键 | 操作 |
| --- | --- |
| 直接输入 | 在光标处输入文字，替换已有选区 |
| 方向键 | 移动光标 |
| `Home` / `End` | 行首 / 行尾 |
| `Ctrl+Home` / `Ctrl+End` | 文件开头 / 结尾 |
| `Ctrl+Left` / `Ctrl+Right` | 按词移动 |
| `Shift` + 上述移动键 | 扩展选区 |
| `PageUp` / `PageDown` | 向上 / 向下一页 |
| `Ctrl+A` | 全选 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴，使用系统剪贴板 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Backspace` / `Delete` | 删除光标前 / 后字符；有选区时删除选区 |
| `Enter` | 换行 |
| `Tab` | 插入一个 Tab |
| 左键拖动 / `Shift` + 单击 | 选择文本 / 扩展选区 |
| 横向滚轮 / `Shift` + 滚轮 | 横向滚动 |

文本搜索按字面匹配、区分大小写，全部匹配项高亮，当前结果用另一种颜色。
Vim 的 `Space Enter` 可以清除高亮，`n` 或 `F3` 继续搜索时恢复。

## Diff

| 按键 | 操作 |
| --- | --- |
| `[` / `p` | 上一个修改块 |
| `]` / `n` | 下一个修改块 |
| `s` / `u` | 暂存 / 取消暂存当前修改块 |
| `e` | 打开工作区文件进行编辑 |
| `Tab` / `Ctrl+D` | 切换统一 / 并排布局 |
| `Left` / `Right` | 横向滚动，两侧同步 |
| `Enter` | 保留当前预览标签 |
| 左键拖动 / `Shift` + 单击 | 选择源文本；并排 Diff 在单侧选择 |
| `Ctrl+C` | 复制选中源文本 |
| 横向滚轮 / `Shift` + 滚轮 | 横向滚动 |

新增 / 删除文件始终使用全宽统一 Diff；内容区域过窄时并排布局也回退为统一布局。
提交 Diff 为只读，暂存操作受当前 Diff 来源限制。

## 图片

| 按键 / 鼠标 | 操作 |
| --- | --- |
| 滚轮向上 / 向下 | 以指针位置为中心放大 / 缩小 |
| `+` / `=` / `-` | 以视口中心放大 / 缩小 |
| 方向键 / 左键拖动 | 平移 |
| `0` | 恢复适应窗口 |
| `Enter` | 保留当前预览标签 |

## 文件、命令等选择器

| 按键 | 操作 |
| --- | --- |
| 输入文字 / 粘贴 | 搜索或填写内容 |
| `Up` / `Down` | 上一项 / 下一项 |
| `PageUp` / `PageDown` | 上一页 / 下一页 |
| `Home` / `End` | 第一项 / 最后一项（列表选择器） |
| `Enter` | 确认或执行所选项 |
| `Esc` | 取消 |

文件与命令共用输入框：以 `>` 开头搜索命令，以 `:` 开头跳转行列，其他文字搜索文件。
具体确认弹窗以屏幕提示为准。
