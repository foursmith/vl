# vl 的 Vim 键位

<p align="center">
  <a href="VIM.md">English</a> · 简体中文
</p>

文本文件打开后进入**普通模式**（Normal mode）。按 `i` 进入插入模式，按 `v` 进入可视模式，按 `Esc` 或 `Ctrl+[` 回到普通模式。只读的 diff 编辑器也支持相同的光标移动、选区、yank 和跳转操作。工作台的其他按键见[键盘快捷键](KEYBINDINGS.zh-CN.md)。

## vl 与 Vim 的区别

| 按键 | vl | 原生 Vim |
| --- | --- | --- |
| `H` / `L` | 跳到当前行第一个非空白字符 / 行尾，相当于 `^` / `$` | 跳到窗口顶部 / 底部 |
| `f`、`df`、`cf`、`yf` | 用 Flash 跳转，或从光标处操作到视口内标了标签的目标 | `f{char}` 在当前行查找字符 |
| `U` | 重做，`u` 仍用于撤销 | 恢复上一次修改过的行。重做用 `Ctrl+R`。 |
| `:` | 输入保存或退出命令，或跳到指定行、列，例如 `:42` 或 `:42:8` | 输入 Ex 命令 |
| `/`、`n` | 打开查找框、跳到下一处匹配 | 输入搜索模式、重复搜索。`N` 反向搜索。 |
| `Space` | 编辑器标签页里的 Leader 键，例如用 `Space →` 切到下一个标签页 | 在普通模式下右移 |
| `Ctrl+V` | 在文本编辑器里从系统剪贴板粘贴 | 在普通模式下进入可视块模式 |
| `Ctrl+R` | 打开最近的工作区 | 在普通模式下重做 |
| `Ctrl+F` / `Ctrl+W` | 查找 / 关闭编辑器 | 在普通模式下向下翻页 / 输入窗口命令的前缀 |
| `Tab` / `Shift+Tab` | 在普通模式和可视模式下增加 / 减少缩进 | 在普通模式下按 `Tab`，跳到跳转列表中的下一项 |
| 反引号 | 向左移到词首并切换大小写。在可视模式中，用同一动作扩展选区，再切换选区的大小写。 | 跳到标记 |
| diff 中的 `[` / `]` | 上一个 / 下一个修改块（hunk） | 以方括号开头的命令前缀 |

Vim 的默认行为见[移动命令](https://vimhelp.org/motion.txt.html)、[撤销和重做](https://vimhelp.org/undo.txt.html)和[命令索引](https://vimhelp.org/index.txt.html)。

**注意区分寄存器和系统剪贴板。** `y` 将文本复制到 vl 的无名寄存器。`d`、`c`、`x` 和 `s` 也会把删除的文本写入这个寄存器。`p` 和 `P` 从无名寄存器粘贴，它由各个编辑器标签页共用。例如，`ddp` 会把当前行下移一行。在普通、可视和插入模式下，可以用 `Ctrl+C`、`Ctrl+X` 和 `Ctrl+V` 通过系统剪贴板复制、剪切和粘贴。复制和剪切需要选区，剪切和粘贴需要可编辑的文本文件。资源管理器的 `yy` 和 `p` 使用独立的文件剪贴板。

vl 实现了 Vim 的一部分功能，包括可视模式下按字符和按行选择，以及下文列出的保存与退出命令。可视块模式、宏、命名寄存器、其他 Ex 命令和标记跳转暂不支持。

## 光标移动与搜索

以下移动命令适用于普通模式和可视模式。加上数字前缀可以重复移动，例如 `3j` 或 `2w`。

| 按键 | 移动 |
| --- | --- |
| `h j k l` / 方向键 | 左、下、上、右 |
| `w` / `b` / `e` | 向右跳到词首 / 向左跳到词首 / 跳到词尾 |
| `0` / `Home` | 跳到行首，包含缩进 |
| `^` / `H` | 跳到当前行第一个非空白字符 |
| `$` / `L` / `End` | 跳到行尾 |
| `gg` / `G` | 跳到首行 / 末行 |
| `5gg` / `5G` | 跳到第 5 行 |
| `PageUp` / `PageDown` | 向上 / 向下翻页 |
| `Ctrl+U` / `Ctrl+D` | 向上 / 向下滚动半屏 |

`w`、`b`、`e` 移动和 `iw`、`aw` 文本对象使用 Vim 默认的 UTF-8 字符类别。例如 `foo_中文かな。🙂` 会分成 `foo_`、`中文`、`かな`、`。` 和 `🙂`。 `w` 和 `b` 也会在空行停靠。

要开启中文按词移动，在 `~/.config/vl/vl.json` 中设置 `vim.enableJieba`。

```json
{
  "vim": {
    "enableJieba": true
  }
}
```

任选一个 Jieba 词典下载到 `~/.config/vl/extra/`，再重开 vl。如果目录里有多个版本，vl 会按表格从上到下的顺序使用第一个可用文件。

| 词典 | 下载大小 | 词汇覆盖 |
| --- | ---: | --- |
| [`dict.txt`](https://raw.githubusercontent.com/fxsjy/jieba/v0.42.1/jieba/dict.txt) | 4.84 MiB | Jieba 默认使用的标准词典。 |
| [`dict.txt.small`](https://raw.githubusercontent.com/fxsjy/jieba/v0.42.1/extra_dict/dict.txt.small) | 1.48 MiB | 词条最少，下载文件也最小。 |
| [`dict.txt.big`](https://raw.githubusercontent.com/fxsjy/jieba/v0.42.1/extra_dict/dict.txt.big) | 8.19 MiB | 词条最多，繁体词汇覆盖更广。 |

如果还想识别生词，可以把 [CppJieba 的 `hmm_model.utf8`](https://raw.githubusercontent.com/yanyiwu/cppjieba/v5.6.7/dict/hmm_model.utf8) 下载到同一目录。

在普通模式下，`/` 和 `Ctrl+F` 打开的是同一个查找框。匹配项会高亮，跳转时会把当前匹配项滚到视图中央。按 `n` 跳到下一处，也会重新显示已隐藏的高亮。完整键位见[查找和替换](KEYBINDINGS.zh-CN.md#查找和替换)。

## 普通模式下的编辑

| 按键 | 操作 |
| --- | --- |
| `i` / `a` | 在光标前 / 光标后进入插入模式 |
| `I` / `A` | 在第一个非空白字符前 / 行尾进入插入模式 |
| `o` / `O` | 在下方 / 上方新建一行并进入插入模式 |
| `x` / `s` | 删除字符 / 删除字符并进入插入模式。两者都支持数字前缀。 |
| `r{char}` | 原地替换字符。例如 `3rX` 会写入 `XXX`。 |
| `dd` / `cc` / `yy` | 删除 / 修改 / 复制当前行 |
| `D` / `C` | 删除到行尾 / 删除到行尾并进入插入模式 |
| `J` | 将当前行与下一行合并。`3J` 合并三行。 |
| `p` / `P` | 粘贴到光标后 / 光标前。按行复制的文本粘贴到当前行下方 / 上方。 |
| `u` / `U` | 撤销 / 重做。两者都支持数字前缀。 |
| `.` / `3.` | 重复上一次修改一次 / 三次 |
| `Tab` / `Shift+Tab` | 增加 / 减少当前行的缩进 |

一次插入模式里的输入会归为一次撤销操作。点号重放支持普通编辑、已结束的插入操作、可视模式下的编辑、粘贴、缩进、大小写转换、Flash 编辑和 Surround。在插入模式中移动光标或撤销时，仍可重放之前那次修改。

### 操作符与文本对象

把 `d`（删除）、`c`（修改）或 `y`（复制）与移动命令或文本对象组合使用。`c` 执行后会进入插入模式。操作符前后的数字前缀会相乘。

| 示例 | 操作 |
| --- | --- |
| `dw` / `de` | 删除到下一个词的词首 / 删到当前词尾（包括词尾字符） |
| `cw` | 修改到当前词尾（包括词尾字符）。光标在空白处时，修改到下一个词的词首。 |
| `d0` / `d^` / `d$` | 删除到行首 / 第一个非空白字符 / 行尾 |
| `dj` / `dk` | 删除当前行和下一行 / 上一行 |
| `2dd` / `d2w` / `2d3w` | 删除两行 / 按两次 `w` 的范围删除 / 按六次 `w` 的范围删除 |
| `diw` / `daw` | 删除当前词 / 删除当前词和相邻空白 |
| `ci"` / `da(` / `yi{` | 修改引号内的文本 / 删除一对圆括号及其内容 / 复制花括号内的文本 |

`i` 选内部（inner），`a` 选整个对象（around）。在可视模式中也可以直接用文本对象选择文本。

| 对象 | 内部 / 整个对象 | 说明 |
| --- | --- | --- |
| word | `iw` / `aw` | 按词和标点的边界划分 |
| WORD | `iW` / `aW` | 以空白分隔，标点也算在内 |
| 引号 | `i"` / `a"`、`i'` / `a'`、`i` / `a` 后跟反引号 | 仅在当前行匹配 |
| 圆括号 | `i(` / `a(` | `)` 和 `b` 都可以替代 `(` |
| 方括号 | `i[` / `a[` | `]` 可以替代 `[` |
| 花括号 | `i{` / `a{` | `}` 和 `B` 都可以替代 `{` |
| 尖括号 | `i<` / `a<` | `>` 可以替代 `<` |

圆括号、方括号和花括号支持嵌套和跨行匹配。

## 可视模式

| 按键 | 操作 |
| --- | --- |
| `v` / `V` | 进入按字符 / 按行选择的可视模式。再按一次同一个键即可退出。 |
| 移动命令或文本对象 | 扩展选区或选中文本对象 |
| `o` | 将光标切到选区另一端 |
| `y` | 复制并退出可视模式 |
| `d` / `x` | 删除并退出可视模式 |
| `c` | 修改选区并进入插入模式 |
| `p` / `P` | 用无名寄存器中的文本替换选区 |
| `J` | 合并选中的行（至少两行）并退出可视模式 |
| `Tab` / `Shift+Tab` | 增加 / 减少缩进，保留选区 |
| `>` / `<` | 增加 / 减少缩进，并退出可视模式 |
| `S{delimiter}` | 给选区加上成对的定界符 |
| `Esc` / `Ctrl+[` | 清除选区并回到普通模式 |

## 插入模式

| 按键 | 操作 |
| --- | --- |
| 方向键、`Home` / `End` | 移动光标 |
| `Ctrl+Left` / `Ctrl+Right` | 按词移动 |
| `Ctrl+Home` / `Ctrl+End` | 跳到文件开头 / 末尾 |
| `Shift` 加上上述任一移动键 | 扩展选区 |
| `PageUp` / `PageDown` | 向上 / 向下翻页 |
| `Ctrl+U` / `Ctrl+D` | 向上 / 向下滚动半屏 |
| `Ctrl+A` | 全选 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 使用系统剪贴板复制 / 剪切 / 粘贴 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Backspace` / `Delete` | 删除选区，或删除光标前 / 光标后的字符 |
| `Enter` / `Tab` | 插入换行符 / 制表符 |

输入 `./` 或 `../` 可以补全相对于当前文件的路径。用 `Up` / `Down` 选择候选项，按 `Tab` 确认。确认目录后会补上 `/` 并列出目录内容。带空格的路径要用引号包起来。

## Flash

按 `f`，输入要匹配的原文，再按目标处显示的标签。Flash 会搜索完整可见的文本，包括固定在视图里的上下文行。在可视模式中，跳转会扩展选区。交互方式参考了 [flash.nvim](https://github.com/folke/flash.nvim)。

| 按键 | 操作 |
| --- | --- |
| 继续输入 | 缩小匹配范围 |
| 目标标签 | 跳到对应的匹配项 |
| `Enter` | 跳到当前这页标签里的第一个目标 |
| `Tab` / `Shift+Tab` | 显示标签或在多页标签之间翻页 |
| `Esc` | 取消，保留原来的光标位置和选区 |
| `df` / `cf` / `yf` | 删除 / 修改 / 复制到目标的第一个字符（包含该字符） |
| `ysf` | 选中目标后输入定界符，给这一段文本加上成对的定界符 |

Flash 的操作符使用无名寄存器。用点号重放 `df` 或 `cf` 时，会重新查找同一段文本。

## Surround

| 按键 | 操作 |
| --- | --- |
| `ysiw"` | 给当前词加上双引号 |
| `ysaw]` | 给当前词及相邻的空白加上方括号 |
| `ysw)` / `yse)` | 给移动命令覆盖的范围加上圆括号 |
| `yss)` / `2yss]` | 给当前行加圆括号 / 给当前行和下一行加方括号 |
| `ysL]` / `ysG]` / `ysgg]` | 给到行尾 / 到文件末行 / 回到文件首行的范围加方括号 |
| 可视模式下的 `S"` / `S]` | 给选区加上双引号 / 方括号 |
| `cs([` / `cs"'` | 把圆括号换成方括号 / 把双引号换成单引号 |
| `ds(` / `ds"` | 去掉定界符，保留里面的文本 |
| `2cs([` / `2ds(` | 替换 / 删除外一层的圆括号 |

Surround 支持引号、反引号和 `() [] {} <>`。输入成对括号中的任意一边即可。操作会保留内部空白和无名寄存器的内容。撤销和点号重放都以整次修改为单位。

## 折叠

| 按键 | 操作 |
| --- | --- |
| `za` | 切换当前块的折叠状态 |
| `zc` / `zo` | 折叠 / 展开当前块 |
| `zC` / `zO` | 递归折叠 / 展开当前块 |
| `zM` / `zR` | 折叠 / 展开文件里的所有块 |

折叠按花括号代码块和 Python 缩进识别。移动光标时会跳过折叠的行。如果搜索或行号跳转的目标在折叠块内，编辑器会展开该块。编辑会清除折叠状态。重新打开文件时，仍能匹配到原有边界的块会恢复之前保存的折叠状态。

## 保存与退出命令

按 `Ctrl+S` 保存，按 `Ctrl+W` 关闭当前编辑器。习惯用 Vim 的话，也可以在普通模式下输入以下命令。先按 `:`，输入余下的命令，再按 `Enter`。

| 命令 | 操作 |
| --- | --- |
| `:w` / `:w!` | 保存当前文件 |
| `:q` | 在没有未保存更改时关闭当前编辑器 |
| `:q!` | 关闭当前编辑器并丢弃未保存的更改 |
| `:wq` / `:wq!` | 保存当前文件并关闭编辑器 |

在工作区中，关掉最后一个编辑器后会回到工作区。单文件模式下，关掉最后一个编辑器会退出 vl。保存命令会遵守文件的只读状态，并检测磁盘上的改动，带 `!` 的命令也会做这些检查。如果要打开的文件刚好和这些命令同名，在文件名前加 `./`。

插入模式之外也可以使用以下 Leader 按键序列。

| 按键序列 | 操作 |
| --- | --- |
| `Space w` | 保存 |
| `Space q` | 关闭编辑器。有未保存的更改时会提示。 |
| `Space z` | 保存并关闭 |

`Space q` 也可以关闭 diff 和图片标签页。保存命令适用于可编辑的文本文件。

## Leader 与标签页

在编辑器标签页中，插入模式之外用 `Space` 作为 Leader。按顺序逐个按键。如果序列还没输入完，按 `Esc` 可以取消。

| 按键 | 操作 |
| --- | --- |
| `Space 1` … `Space 9` | 按从左到右的编号切换标签页 |
| `Space ←` / `Space →` | 切到左侧 / 右侧相邻的标签页 |

在 diff 和图片预览里也可以用这些按键切换标签页。
