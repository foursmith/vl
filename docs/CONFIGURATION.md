# Configure VL

## Edit settings

Press `Ctrl+,` to open `~/.config/vl/vl.config.json`. It accepts JSONC comments and trailing commas. After making a manual edit, save with `Ctrl+S`, then run **Reload VL** from the command palette.

For visual settings, press `Ctrl+P` and choose **Appearance: Color Theme**, **Appearance: Toggle Sidebar Position**, or **Appearance: Toggle Sidebar Visibility**.

## Customize keys and input

- Run **Preferences: Toggle Vim Mode** from the command palette to enable or disable [Vim keybindings](VIM.md).
- See [how to remap workbench shortcuts](KEYBINDINGS.md#shortcuts-you-can-currently-customize) for the keyboard shortcuts file and configuration example.
- [Enable Chinese word segmentation](CHINESE-WORD-SEGMENTATION.md) for motions and selection.
- [Set up automatic input method switching](INPUT-METHOD.md) for keyboard navigation.
