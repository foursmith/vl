# 键盘快捷键

<p align="center">
  <a href="KEYBINDINGS.md">English</a> · 简体中文
</p>

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+G` | 转到文件 |
| `Ctrl+P` | 打开命令面板 |
| `Ctrl+F` | 在当前文件中查找 |
| `F2` | 在侧边栏和编辑器之间切换焦点 |
| `Ctrl+S` | 保存当前文件 |
| `Ctrl+W` | 编辑器或侧栏列表获得焦点时，关闭当前编辑器。有未保存的更改时会提示。 |
| `Esc` | 退出当前模式、关闭菜单或取消输入 |

文件默认以普通模式（Normal mode）打开。在命令面板选择**首选项：切换 Vim 模式**可改为直接编辑。[Vim 指南](VIM.zh-CN.md)介绍了光标移动和[兼容的保存与退出命令](VIM.zh-CN.md#保存与退出命令)。

用 `Ctrl+U` / `Ctrl+D` 在当前视图中向上 / 向下滚动半屏。文本和 diff 编辑器在开启或关闭 Vim 模式时都支持这两个键，侧边栏列表、选择器、菜单以及确认对话框里可滚动的详情也适用。在工作区搜索中，它们用于浏览搜索结果。在文件内查找时，它们滚动文档，焦点仍在输入框中。图片放大后，可以用它们上下平移图片。

列表获得焦点时，用 `j` / `k` 下移 / 上移，用 `gg` / `G` 跳到首行 / 末行，用 `PageUp` / `PageDown` 翻页。

按键区分大小写。`Ctrl+G` 要同时按下，`gg` 这样的按键序列要逐个输入。

## 工作台

在确认对话框中，用 `←` / `→` 或 `Tab` 选择按钮，按 `Enter` 执行，按 `Esc` 取消。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+R` | 打开最近的工作区。有未保存的更改时会提示。 |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+4` / `Ctrl+5` | 分别将焦点切到资源管理器、搜索、更改、提交历史、拉取请求 |
| `F12` | 显示或隐藏侧边栏 |
| `Ctrl+Shift+W` | 关闭其他标签页。有未保存的更改时会提示。 |
| `Space 1` … `Space 9` | 按编号切换标签页。要求编辑器有焦点、已开启 Vim 模式且未进入插入模式。 |
| `Space ←` / `Space →` | 切换到相邻标签页。要求编辑器有焦点、已开启 Vim 模式且未进入插入模式。 |
| `F5` | 刷新当前视图。在编辑区检查当前文件的磁盘变化，并保留未保存的修改。 |
| `F7` / 鼠标右键 | 打开上下文菜单 |
| `Ctrl+Q` | 退出。有未保存的更改时会提示。 |

「转到文件」按文件名或路径筛选，无需 Git。输入 `src/main.go:42:8` 可打开文件并跳到第 42 行第 8 列，输入 `:42` 可跳到当前文件的第 42 行。在工作区中，按 `F4` 或点击输入框旁的忽略规则图标可以显示被忽略的文件。输入 `>` 可查找命令。

单文件模式下，「转到文件」列出与当前文件同目录的文件。

在选择器中，`Down` / `Up` 或 `Ctrl+J` / `Ctrl+K` 选择下一条 / 上一条结果。`PageUp` / `PageDown` 翻页，`Home` / `End` 跳到第一条 / 最后一条结果。`Enter` 确认，`Esc` 关闭。路径补全也支持方向键、`Ctrl+J` / `Ctrl+K` 和半页或整页滚动，按 `Tab` 插入选中的路径。保存与退出命令见 [Vim 指南](VIM.zh-CN.md#保存与退出命令)。

### 文字编辑

这组快捷键作用于当前有焦点的文本编辑器或输入框，开启或关闭 Vim 模式都可以使用。只读 diff 支持全选和复制。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+A` | 全选 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 通过系统剪贴板复制 / 剪切 / 粘贴 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |

双击按 [Vim 的词边界](VIM.zh-CN.md#光标移动与搜索)选中单词，关闭 Vim 模式时也适用。三击选中整行。三击单行输入框会选中整个输入框的内容。在输入框中，按住 `Ctrl` 再按左右方向键可按词移动，按住 `Shift` 再按移动键可扩展选区。`Ctrl+Backspace` 删除光标前的一个词，`Ctrl+Delete` 删除光标后的一个词。

### 终端兼容性

有些终端会用旧版输入编码发送 `Ctrl+1` 到 `Ctrl+5`。这些快捷键无法使用时，可以点击侧边栏图标，或按 `Ctrl+P` 打开命令面板，按名称选择视图。要搜索工作区，选择**搜索：在文件中查找**。

Windows Terminal 可以自己处理 `Ctrl+V`，编辑器通过 bracketed paste 接收终端发来的文本。如果终端本身有选区，`Ctrl+C` 可能会复制终端里的选区。要复制 vl 里的选区，可以用编辑器的上下文菜单。

## 侧边栏

| 快捷键 | 操作 |
| --- | --- |
| `Tab` / `Shift+Tab` | 循环切到下一个 / 上一个侧边栏视图 |
| `j` / `k` 或 `Down` / `Up` | 选中并预览下一项 / 上一项 |
| `gg` / `G` | 选中第一项 / 最后一项 |
| `3j`、`5gg`、`5G` | 向下移动三项，或跳到第五项 |
| `PageUp` / `PageDown` | 翻页 |
| `h` / `Left` | 选中可见的父级，保留当前的折叠状态 |
| `l` / `Right` / `Enter` | 展开或折叠文件夹，或打开选中的条目 |
| `e` | 打开所选文件进行编辑（适用于可编辑文件的视图） |
| `r` | 刷新当前视图 |
| `o`（拉取请求） | 在浏览器中打开选中的 PR |

切换选中项或单击文件时，会复用预览标签页，焦点留在侧边栏。用 `Enter` 或 `l` 打开文件、按 `F2` 切到编辑器，或者点击编辑器或标签页，都会保留该标签页。滚动和缩放图片时，标签页仍处于预览状态。在窄窗口中，按 `Enter` 打开条目，按 `F2` 切回侧边栏。

视图按侧边栏图标的顺序循环切换。切到搜索视图时，焦点先落在结果列表。按 `/` 编辑搜索词。

### 资源管理器

| 快捷键 | 操作 |
| --- | --- |
| `o` | 在文件树和大纲之间切换焦点 |
| `t` | 在文件树和时间线之间切换焦点 |
| `L` | 拆开选中的紧凑文件夹路径 |
| `dd` / `Delete` | 确认后删除选中的文件或文件夹 |
| `yy` | 将选中的文件或文件夹复制到资源管理器的文件剪贴板 |
| `p` | 粘贴到选中的文件夹内，或选中文件所在的目录。粘贴前需要确认目标路径。 |

`dd` 和 `yy` 每次操作一个条目，选中文件夹时也会处理其子项。复制前先保存源文件的更改。粘贴范围限于当前工作区，拒绝处理符号链接和特殊文件，并跳过 `.git` 元数据。已有文件和目录受保护。如果复制到源条目的父目录，且默认目标就是源条目本身，vl 会建议使用带 `-copy` 后缀的名称。

当前文件为 Markdown 时会显示大纲。用 `j` / `k` 选中章节，再按 `Enter` 跳转，也可以直接点击条目。点击大纲标题可以展开或折叠大纲。焦点在大纲内时，按 `Left` 折叠，按 `Right` 重新展开。

资源管理器底部的大纲和时间线共用一组折叠面板，展开一个会收起另一个。时间线跟随当前文件。点击提交，或在时间线内按 `j` / `k`，即可预览该文件的差异。双击或按 `Enter` 保留 diff 标签。点击时间线标题可折叠或展开。也可以通过文件右键菜单或命令面板里的**查看文件历史**打开时间线。

### 更改

| 快捷键 | 操作 |
| --- | --- |
| `s` | 暂存工作区条目，或取消暂存已暂存的条目。作用范围取决于所选的文件、文件夹或分组。在仓库标题行上按此键会暂存该仓库的更改。 |
| `Shift+S` | 在工作区条目上暂存所选仓库的所有更改，在已暂存条目上取消该仓库的所有暂存。在仓库标题行上，有可暂存的更改时优先暂存。 |
| `c` | 提交 |
| `d` | 对选中的未暂存条目打开「放弃更改」对话框 |
| `Shift+D` | 确认后放弃所选仓库中所有未暂存的更改。可在工作区条目或仓库标题行上使用。 |
| `t` | 打开「储藏更改」，包括未跟踪文件 |
| `f` | 提取（fetch） |
| `p` / `P` | 拉取（仅快进） / 推送 |

行内按钮、上下文菜单和命令面板的操作范围一致。整个仓库的操作也会处理折叠起来的文件，且只作用于该仓库的 Git 索引。

从「更改」的上下文菜单或命令面板打开**管理储藏…**，可以查看所选仓库的 stash。选中一条 stash 后会列出其中的文件，再选择文件查看 diff。用文件列表里的**储藏操作…**可以应用、弹出或删除 stash。应用和弹出时也可以恢复暂存状态。用**新建储藏…**可以选择储藏范围，例如仅储藏已暂存的更改、仅储藏已跟踪文件的更改，或储藏已跟踪文件的更改并保留暂存区。

## 查找和替换

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+F` / 普通模式下按 `/` | 在编辑器中打开查找 |
| 普通模式下按 `n` | 查找下一处 |
| 在查找框中按 `↑` / `↓` 或 `Ctrl+K` / `Ctrl+J` | 跳到上一处 / 下一处匹配 |
| 在查找框中按 `Enter` | 跳到匹配处并把焦点交回编辑器 |
| `Tab` / `Shift+Tab` | 在查找框和替换框之间切换。替换框收起时，返回编辑器。 |
| 在替换框中按 `Enter` | 替换当前匹配项 |
| `Esc` | 关闭查找并隐藏高亮 |

查找框浮在编辑器右上角，与工作区搜索共用搜索词、替换文本和匹配选项。查找上一处或下一处时会循环跳转。匹配选项包括区分大小写、全字匹配和使用正则表达式，替换还支持保留大小写。点击展开箭头可以显示或隐藏替换框，点击「全部替换」可以替换文件内的所有匹配项。替换文本可以引用捕获组，例如 `$1` 和 `${name}`。文件内替换先写入编辑缓冲区，保存后才会写入磁盘。只读 diff 也支持查找。

在查找或搜索输入框内按 `F7`，或右键点击搜索表单，然后选择「搜索选项」。

### 跨文件搜索

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+2` | 在文件中查找 |
| 在输入框中按 `Tab` / `Shift+Tab` | 在可见的输入框和结果列表之间切换 |
| 在搜索框中按 `Enter` | 执行搜索并将焦点移到结果列表 |
| 在输入框中按 `Esc` | 将焦点移到结果列表 |
| 在输入框中按 `Ctrl+J` / `Ctrl+K` | 选中下一条 / 上一条结果，焦点仍在输入框 |
| 在结果列表中按 `/` / `Ctrl+F` | 将焦点移到搜索框 |
| 在结果列表中按 `j` / `k`、`gg` / `G`、`PageUp` / `PageDown` | 在匹配项和按文件分组的结果之间移动 |
| 在结果列表中按 `h` / `l` | 选中上级文件分组 / 展开分组或打开所选结果 |
| 在结果列表中按 `Enter` | 打开选中的文件或匹配项，并保留标签页 |
| 在结果列表中按 `dd` / `Delete` | 移除匹配项或文件分组，操作仅作用于搜索结果 |
| 在替换框中按 `Enter` | 替换选中的匹配项，或替换选中文件分组中保留的所有匹配项 |

搜索会随输入更新，也会查找尚未保存的编辑内容。打开结果后，按 `n` 可以继续查找当前文件。`rg`（ripgrep）可选，只有「仅搜索有更改的文件」需要 Git 仓库。

展开「搜索详情」可以限定为已打开的标签页或有更改的文件，也可以填写包含和排除条件。多个 glob 用逗号分隔，例如 `*.go, **/*.{ts,tsx}`。`./src` 仅匹配工作区根目录下的 `src` 目录及其内容。排除优先于包含。

搜索和「转到文件」都遵循工作区内的忽略规则，优先级从高到低为 `.rgignore`、`.ignore`、`.gitignore`。要搜索被忽略的目录，可以关闭排除框右侧的「遵循忽略规则」，或者在包含框里填入目录本身，例如 `./dist`。

点击展开箭头打开替换框。「全部替换」只处理列表中保留的结果，可先按 `dd` 或 `Delete` 跳过个别匹配项或整个文件。

## Diff 编辑器

Diff 编辑器是只读的。光标移动、可视模式选区、yank、查找和 Flash 的按键与文本标签页相同。

| 快捷键 | 操作 |
| --- | --- |
| 普通模式下按 `[` / `]` | 跳到上一个 / 下一个修改块（hunk） |
| `s` | 暂存或取消暂存选中的更改行。没有选区时，对当前修改块生效。 |
| `Shift+S` | 暂存或取消暂存整个文件 |
| `d` | 确认后放弃选中的更改或当前修改块 |
| `Shift+D` | 确认后放弃此文件中所有未暂存的更改 |
| `F7` / 鼠标右键 | 打开 diff 操作菜单，可以暂存、取消暂存，或放弃未暂存的修改块及选中的更改 |
| `Ctrl+C` | 将选中的原文复制到系统剪贴板 |
| `Space 1` … `Space 9` | 切换标签页 |

可以用 diff 工具栏切换布局，也可以从命令面板或 diff 上下文菜单选择**切换内联视图**。在并排布局中，键盘在右侧窗格里导航，鼠标可以在两侧选择文本。用 yank 或复制时会自动去掉行号和 diff 标记。新增或删除的文件会用内联布局打开，窗口放不下并排视图时也会切回内联布局。

将鼠标移到工作区的修改块上，会显示 `→`（确认后放弃）和 `+`（暂存）。移到已暂存的修改块上，会显示 `−`（取消暂存）。如果块内有选中的更改，按钮只处理这个块里选中的更改。二进制 diff 按整个文件操作。提交历史和 PR 里的 diff 是只读的。

暂存或取消暂存后，如果当前 diff 标签页所在一侧已经没有更改，标签页会切到更改移入的一侧。如果两侧的标签页已经打开，会复用目标侧的标签页。

## 图片预览

点击图片或它的标签页，可以保留该预览标签页。

| 快捷键 | 操作 |
| --- | --- |
| `+` / `=` / `-` | 以视口中心为基准缩放，`+` 和 `=` 放大，`-` 缩小 |
| 鼠标滚轮 | 以指针位置为基准缩放 |
| `h j k l` / 方向键 / 拖动 | 平移图片，按键支持数字前缀 |
| `0` | 缩放到适合窗口的大小 |
| `Space 1` … `Space 9` | 切换标签页 |

## 菜单和对话框

| 快捷键 | 操作 |
| --- | --- |
| `k` / `j`、`Up` / `Down`、`Shift+Tab` / `Tab` | 选择上一项 / 下一项菜单操作 |
| `Home` / `End` | 选择第一项 / 最后一项菜单操作 |
| `l` / `Enter` / `Space` | 执行选中的操作 |
| `h` / `Esc` / `F7` | 关闭上下文菜单 |

按菜单项右侧显示的快捷键，可以直接执行该操作。

在更改、提交历史和拉取请求视图中，右击仓库行，或选中仓库行后按 `F7`，即可从菜单切换分支。更改和提交历史的菜单还提供同步、拉取、推送、发布等远端操作。

发布会为当前分支设置上游分支。只有一个远端时会直接推送，有多个远端时会打开选择器。还没有远端时，可以先运行 `gh auth login` 登录，再通过发布选择器创建私有或公开的 GitHub 仓库。

在确认对话框中，用 `h` / `l` 切换按钮，用 `j` / `k` 滚动详情。按 `Enter` 执行当前聚焦的按钮，按 `Esc` 取消。

## 在代码中添加快捷键

要给已有的工作台命令绑定按键，修改 [keymap.go](../internal/app/keymap.go) 中的 `workbenchKeybindings`。每条规则声明命令 ID、显示名称、可用的按键名和焦点条件。备用按键可以加到同一条规则里。需要不同的焦点条件时，可以为同一条命令再加一条规则。命令面板和菜单都从这张表读取快捷键提示。新操作在 [workbench_commands.go](../internal/app/workbench_commands.go) 中定义。

工作台会将默认规则编译成一份键位映射，供按键分发和快捷键提示共用。规则 ID 默认使用命令 ID。一个命令有多个绑定，且焦点条件不同时，为规则指定显式 ID。构建键位映射时，可以按顺序根据规则 ID 设置、替换或移除绑定，同时保留每条规则的命令和焦点条件。没有默认按键的规则也可以供用户自行绑定。

添加新列表时，如果输入焦点在文本框里，用 `listNavigationKey` 处理导航。如果焦点在列表里，而且列表支持 Vim 按键序列，用 `navigationState.key`。逐行移动和翻页用 `moveListSelection`，预览、跳过不可选中的标题等组件特有的行为放在调用方处理。
